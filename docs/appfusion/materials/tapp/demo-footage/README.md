# Tapp demo footage

These MP4s are editing source material for the AppFusion presentation.

| File | What to use it for |
| --- | --- |
| [Tapp-Spotify-Phone-Capture.mp4](./Tapp-Spotify-Phone-Capture.mp4) | An unframed vertical iPhone capture for your own edit. |
| [Tapp-In-Action-Refined-Split.mp4](./Tapp-In-Action-Refined-Split.mp4) | A 20-second landscape edit with close-ups and captions. |
| [Tapp-Launch-1920x1080.mp4](./Tapp-Launch-1920x1080.mp4) | A 20-second landscape intro with original music and Tapp interface shots. |

On GitHub, open a file and choose **Download raw file**, or copy the files from this directory in a local checkout.

The two Spotify clips come from the same Oct 30 iPhone run. Tapp receives “Open up Spotify and search for Daft Punk,” opens Spotify, navigates to Search, types the query, and shows matching results. The edits cut waiting pauses. The footage ends on search results. Credit the clip as pre-event footage and identify the hackathon additions in a fresh walkthrough.

AppFusion requires a 2–3 minute demo and 3–5 screenshots in one Google Drive folder. Use the launch clip as an optional intro and the Spotify footage as a short example of the prior app. [Official student guide](https://aiclubtrusu.vercel.app/events/appfusion/guide)
