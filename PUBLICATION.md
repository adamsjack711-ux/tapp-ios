# Public repository scope

This repository publishes the Tapp iOS client and its presentation and design material.

Included: app and extension source, shared core, tests, development tools, CI configuration, third-party notices, design studies, screenshots, demo videos, and the AppFusion pitch deck.

Excluded: the hosted Tapp backend, the earlier AppFusion wellness-fridge backend, private operational audit records, backend publishing tools, and inherited private Git history. The existing development history is retained privately.

Live hosted AI requires a separately supplied beta access code. The backend service is not provisioned by cloning this repository. Build and setup details are in [the development guide](docs/DEVELOPMENT.md).

The PEM and pairing-record fixtures under `DeveloperTools/rork-device/Tests/` are documented upstream test data. They are not personal signing or live-device credentials. Their original third-party notices are preserved.
